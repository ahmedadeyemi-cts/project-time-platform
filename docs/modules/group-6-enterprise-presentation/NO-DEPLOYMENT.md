# Group 6 deployment boundary

This source package is presentation-only.

It does not:

- create or apply a database migration;
- add or change backend APIs;
- alter permissions or role policy;
- modify the global More menu;
- change Azure, Container Apps, Test, or Production resources;
- create a deployment workflow;
- deploy the application.

The package must be reconciled with current `main`, fully validated, reviewed, and separately authorized before any deployment preparation.
