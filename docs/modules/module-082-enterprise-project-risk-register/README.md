# Module 082 — Enterprise Project Risk Register

Module 082 provides a PMI-aligned, authoritative risk register for threats and opportunities across ProjectPulse projects.

## Operating surfaces

- My-project and scoped portfolio views backed by authoritative project manager and assignment records.
- Cause–event–impact risk statements, configurable categories, nine impact dimensions, probability, inherent exposure, proximity, velocity, and response strategy.
- Residual probability/impact, response cost and schedule impact, triggers, contingency, escalation, issue realization, and governed closure.
- Assigned response actions with due dates, status, completion evidence, immutable revisions, and owner updates.
- 5×5 heatmap, project portfolio, review calendar, overdue views, immutable history, and branded Excel/PDF evidence.

Migration `077_module_082_enterprise_project_risk_register.sql` is additive and follows current `main` migration 075 plus Module 081 migration 076. The route is `#project-risk-register`; the API root is `/api/project-risk-register`.
